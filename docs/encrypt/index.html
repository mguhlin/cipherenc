    A few things to know

    Your password is the key

    Use a long, unique password or the built-in password generator. No account or recovery service exists. An incorrect password or altered package fails authentication.

    ZIP files and mobile folders

    Folder picking varies by Android/iOS browser and system file picker. Password-mode files and folders are ZIP-compressed before encryption. Decryption automatically unzips the archive and restores your original file. Supporting browsers can write the restored tree into a new folder; other browsers offer individual file saves, with ZIP as an optional alternative. Browser pickers usually expose files rather than empty directories.

    Keep this tab open

    Phones may pause background tabs during long operations. Keep the page visible. Available memory, free storage, file count, and browser download behavior limit large packages.

    Keep originals under your control

    The browser cannot reliably shred originals. It keeps selected files untouched. The native desktop app offers optional best-effort shredding after saving and verifying an archive.

    Clear after use

    Credentials and source input clear after a completed result. Clear workspace releases active results; the app also clears them after ten idle minutes. This does not delete downloads or clipboard contents.

    Cryptography and format compatibility

    Password mode uses AES-256-GCM authenticated encryption and Argon2id v1.3 (64 MiB, three passes, one lane, a fresh 128-bit salt). Password-mode file/folder ZIPs use authenticated CS4 records; text packages use PRISMVAULT3. Encrypted password output is decrypted and compared before saving, and input packages are authenticated before restoration. Legacy password packages remain readable. Names and paths inside the package are encrypted; the downloaded filename may still reveal the original basename. Restored files are ordinary, unencrypted originals: protect them accordingly. Encrypted text is shown in a result box for copying as well as saving.

    The .cen extension does not select an algorithm. Native-app XChaCha20-Poly1305 packages require the native app and cannot be opened here. OpenPGP is a separate key-based option in this browser tool; verify recipient fingerprints independently. Integrity checking does not verify a sender’s signature.

    Privacy and device limits

    The application makes no file-content uploads or analytics requests and uses no app cookies, localStorage, sessionStorage, or database. When you open this tool from the website, GitHub Pages receives normal requests for the page and its bundled assets. Your browser, operating system, extensions, downloads, clipboard, device backups, and shared-device access remain under their respective controls.

    This tool has no independent cryptographic certification or institutional approval. For student information, follow your school’s review and data-handling rules. The native desktop app runs offline without a browser.
